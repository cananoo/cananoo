## About me

I like turning ideas into small, useful systems—from AI-assisted workflows and typed model integrations to developer tooling and web experiments. I am currently spending most of my time in Python and the open-source ecosystem.

- 🤖 **AI/ML:** LLM tooling, agents, multimodal research, and inference workflows
- 🧪 **Engineering:** tests, packaging, documentation, CI, and developer experience
- 🌐 **Also exploring:** Go, JavaScript, Solidity, and full-stack prototypes
- 🚀 **Open source:** focused fixes, regression tests, and documentation improvements
